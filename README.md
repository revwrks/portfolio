Production personal portfolio and creative engineering showcase for **Me** ofc. Engineered with clean brutalist aesthetics, tactile microinteractions, procedural audio DSP synthesis, real-time 3D WebGL physics, and strict ATS-compliant print delivery.

## 🛠️ Tech Stack & Engineering Tools

| Domain            | Technology                          | Purpose                                                      |
| :---------------- | :---------------------------------- | :----------------------------------------------------------- |
| **Framework**     | Next.js 16 (App Router + Turbopack) | Server Components, Partial Prerendering, Static Optimization |
| **UI Library**    | React 19                            | Core declarative UI and portals                              |
| **Styling**       | Tailwind CSS v4                     | Geometric utility architecture, custom monospace tokens      |
| **3D Engine**     | Three.js (r187)                     | Canvas textures, matrix transformations, lighting shaders    |
| **Animation**     | GSAP 3 + ScrollTrigger              | Choreographed reveals, pin animations, scrubbed timelines    |
| **Smooth Scroll** | Lenis Scroll                        | Momentum-based physics coupled with GSAP tick loop           |
| **Audio**         | Web Audio API + HTML5 Audio         | Synthesized tactile audio feedback & background playback     |
| **Icons**         | Lucide React                        | High-legibility brutalist line icons                         |

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm, pnpm, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/revwrks/portofolio.git

# Enter project root
cd portofolio

# Install dependencies
npm install
```

### Local Development

```bash
# Start Turbopack dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
# Compile and optimize for production
npm run build

# Start production server
npm run start
```

## 🎵 Customizing Background Music

To use your own background track:

1. Prepare an audio file in `.mp3` format.
2. Rename the file to `bgm.mp3`.
3. Place it inside the `public/audio/` directory:
   ```text
   public/
   └── audio/
       └── bgm.mp3
   ```
   The website will automatically load and loop your track.
