---

## ⚡ Key Architectural Highlights

### 1. Dual-Persona Viscous Fluid Hero
- Reverse-engineered from Lando Norris (`landonorris.com`) interactive hero.
- Dynamic radial fluid mask tracking cursor coordinates with soft edge diffusion.
- Dual visual identities: Fullstack Systems Architect on base layer, Creative Technologist on reveal layer.

### 2. Aesthetic Telemetry Preloader
- Inspired by Photoyoshi (`photoyoshi.com`) and Cappen (`cappen.com`).
- Ultra-high-speed numerical telemetry ticker (`+3 every 10ms`) with bilateral viewfinder HUD.
- Coordinated dual-layer typography exit transition with microsecond audio clicks.

### 3. 3D Isometric Specimen Conveyor
- Three.js WebGL card deck engine rendering production architectures with canvas texture generators.
- Real-time mouse pitch/yaw kinetic damping and scroll-coupled 3D inspection angles.

### 4. Brutalist 1px Hairline Project Index
- High-contrast geometric grid displaying core engineering invariant metrics.
- Kinetic 3D perspective hover cards (`perspective(1000px) rotateX/Y translateZ(40px)`).
- Responsive project specification drawers and direct repository action links.

### 5. Procedural Web Audio DSP & Background Audio
- Zero-external-dependency mechanical switch synthesis using native Web Audio API oscillators and gain envelopes.
- Autoplay-compliant background music loop with first-gesture fallback and smart user mute lock.

### 6. Strict ATS 2-Page Print Delivery
- Clean print-isolated stylesheet (`@media print`) stripping dark canvas backgrounds, navigation chrome, and animations.
- Enforced A4 portrait margins (12mm 15mm), high-contrast typography, and bulletproof page breaks.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm, pnpm, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/revwrks/portofolio.git

# Enter project root
cd portofolio

# Install dependencies
npm install
```

### Local Development

```bash
# Start Turbopack dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
# Compile and optimize for production
npm run build

# Start production server
npm run start
```

## 🎵 Customizing Background Music

To use your own background track:
1. Prepare an audio file in `.mp3` format.
2. Rename the file to `bgm.mp3`.
3. Place it inside the `public/audio/` directory:
   ```text
   public/
   └── audio/
       └── bgm.mp3
   ```
The website will automatically load and loop your track.
