CARA PASANG LAGU BGM:
=======================================
1. Pilih file musik / lagu yang kamu inginkan (format .mp3).
2. Rename filenya jadi: bgm.mp3
3. Taruh file tersebut di dalam folder ini:
   public\audio\bgm.mp3

Begitu file `bgm.mp3` ada di folder ini, player di website akan otomatis memutar lagu tersebut saat tombol SOUND/BGM diklik (atau auto-play)!
Jika file belum ada, player akan menggunakan ambient synthesizer mode sebagai demo.
